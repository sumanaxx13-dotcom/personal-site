# Personal Portfolio & Architecture Site

A lightweight, responsive personal website built with pure semantic HTML5 and vanilla CSS. Features a custom dark cyber-monochrome layout with an ambient canvas grid, zero external fonts, and zero library dependencies.

## Structure
- **Section 01 (Identity):** Bio, background, and core focus areas.
- **Section 02 (Deployments):** Interactive game and tool project showcase.
- **Section 03 (Architecture):** Technical environment and systems stack.
- **Section 04 (Contact):** Verified links to GitHub, itch.io, and communication channels.

## AI Transparency Statement
In accordance with submission guidelines regarding AI usage:
- **How AI was utilized:** AI was consulted as a sounding board to scaffold the initial semantic layout tags and suggest clean CSS custom-property names (`--surface`, `--accent-dim`).
- **Human Work & Modification:** The styling, color choices, typography hierarchy, structure, project descriptions, and Git commits were manually reviewed, curated, and adjusted to match the developer's personal technical workflow. No external frameworks, template generators, or black-box site builders were used.
